Privacy Policy

YT Analytics is a private desktop application used only by its owner to analyze the owner's own YouTube channels.

Data accessed

With your permission, the app uses read-only access to the YouTube Data API, YouTube Analytics API and YouTube Reporting API (scopes: youtube.readonly, yt-analytics.readonly, yt-analytics-monetary.readonly) to read channel and video statistics, including revenue reports.

How data is used and stored

  • Data is used only to show analytics reports to the channel owner.
  • OAuth tokens and report data are stored only on the owner's local computer. There is no server and no database.
  • Data is not sold, shared with, or transferred to any third party, and is not used for advertising.
  • The app never changes anything on YouTube: access is read-only.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions and by deleting the local token files.

Contact

Questions: use the support email shown on the Google sign-in consent screen of this app.
